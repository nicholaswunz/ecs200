Week 9: Downloading and mapping species occurrence data

This is an optional tutorial for anyone working with species occurrence or other spatial data.

Note

This tutorial is optional and not assessed, and it will not be in the exam. Work through it in your own time if maps are relevant to your project. It was inspired by Amanda Buyan and Dax Kellie’s tutorials for the Atlas of Living Australia (ALA).

Maps are one of the most useful tools an ecologist has. A quick map of species observations shows where a species has been recorded, the extent of your data, and possible errors (e.g. a frog recorded in the ocean). In this tutorial you will download records of the motorbike frog (Litoria moorei) in Western Australia since 2000 from FrogID, and map them.

Code 
# Week 9 workshop (optional) - Spatial data
# Written by Nicholas Wu, 1234578, 22/04/2027

# Install these packages once, in the console, if needed:
# install.packages(c("galah", "sf", "ozmaps", "leaflet"))

library(tidyverse)  # data wrangling and plotting
library(galah)      # download data from the Atlas of Living Australia
library(sf)         # work with spatial (map) data
library(patchwork)  # combine plots
library(ozmaps)      # download Australia map

Download observations

Always count the records before downloading them, so you do not accidentally download millions of rows:

Code 
galah::galah_call() %>%                                   # start a query
  galah::galah_identify("Litoria moorei") %>%             # motorbike frog
  galah::galah_filter(year >= 2000,                       # since 2000
                      cl22 == "Western Australia",        # in Western Australia
                      dataResourceName == "FrogID") %>%   # recorded by FrogID
  galah::atlas_counts()                                   # count the records
# A tibble: 1 × 1
  count
  <int>
1  9232

To download the records themselves, you first need to register your email with the ALA and give it to galah:

Code 
galah::galah_config(email = "your-email-here")

galah::atlas_occurrences() downloads the location and date of every record:

Code 
frogs <- galah::galah_call() %>%
  galah::galah_identify("Litoria moorei") %>%
  galah::galah_filter(year >= 2000,
                      cl22 == "Western Australia",
                      dataResourceName == "FrogID") %>%
  galah::atlas_occurrences()

Make a map

The ozmaps package contains outlines of Australian states. Keep Western Australia and plot it with ggplot2::geom_sf(), which draws spatial (sf) objects.

Code 
au_map <- ozmaps::ozmap_data("abs_ste")                        # Australian states
wa_map <- au_map %>%
  dplyr::filter(NAME == "Western Australia")                   # keep WA only

ggplot2::ggplot() +
  ggplot2::geom_sf(data = wa_map, colour = "grey60", fill = "#F5F5F5") +
  ggplot2::theme_bw()

Coordinate reference systems

The Earth is round but maps are flat, so every map uses a coordinate reference system (CRS) to flatten it. Our WA outline uses GDA94:

Code 
sf::st_crs(wa_map)$input
[1] "EPSG:4283"

The same outline looks different in different CRSs. sf::st_transform() changes the CRS:

Code 
crs_gda94 <- ggplot2::ggplot(wa_map) +
  ggplot2::geom_sf(colour = "grey60", fill = "#F5F5F5") +
  ggplot2::labs(title = "GDA94") +
  ggplot2::theme_bw()

crs_wa <- wa_map %>%
  sf::st_transform(crs = 7850) %>%   # a projection designed for WA (GDA2020 / MGA zone 50)
  ggplot2::ggplot() +
  ggplot2::geom_sf(colour = "grey60", fill = "#F5F5F5") +
  ggplot2::labs(title = "EPSG:7850") +
  ggplot2::theme_bw()

crs_canada <- wa_map %>%
  sf::st_transform(crs = 2955) %>%   # a projection designed for Canada!
  ggplot2::ggplot() +
  ggplot2::geom_sf(colour = "grey60", fill = "#F5F5F5") +
  ggplot2::labs(title = "EPSG:2955") +
  ggplot2::theme_bw()

crs_gda94 + crs_wa + crs_canada

Always check that all your spatial layers use the same CRS before combining them.

Add the observations

Plot the outline, then add the records as points (longitude on the x-axis, latitude on the y-axis):

Code 
ggplot2::ggplot() +
  ggplot2::geom_sf(data = wa_map, colour = "grey60", fill = "#F5F5F5") +
  ggplot2::geom_point(data = frogs,
                      ggplot2::aes(x = decimalLongitude, y = decimalLatitude),
                      colour = "#e12744", alpha = 0.5, size = 1) +
  ggplot2::labs(x = NULL, y = NULL) +
  ggplot2::theme_bw()

Where are most records?

With thousands of overlapping points it is hard to see where records are concentrated. ggplot2::geom_bin_2d() counts the records in grid cells instead:

Code 
ggplot2::ggplot() +
  ggplot2::geom_sf(data = wa_map, colour = "grey60", fill = "#F5F5F5") +
  ggplot2::geom_bin_2d(data = frogs,
                       ggplot2::aes(x = decimalLongitude, y = decimalLatitude),
                       binwidth = 0.25) +                    # grid cells of 0.25 degrees
  ggplot2::scale_fill_viridis_c(trans = "log10", direction = -1) +
  ggplot2::labs(x = NULL, y = NULL, fill = "Number of\nrecords") +
  ggplot2::theme_bw()

Most records come from around Perth, where most people live and record frogs.

Interactive map

The leaflet package makes interactive maps you can zoom and pan. Hover over a point to see the date of the record.

Code 
# Convert the table to a spatial object with longitude/latitude coordinates (CRS 4326)
frogs_sf <- frogs %>%
  tidyr::drop_na(decimalLongitude, decimalLatitude) %>%
  sf::st_as_sf(coords = c("decimalLongitude", "decimalLatitude"), crs = 4326)

leaflet::leaflet() %>%
  leaflet::addTiles() %>%                  # background map
  leaflet::addCircles(data = frogs_sf,
                      label = ~as.character(eventDate),
                      color = "#e12744")

Seasonality

galah::galah_group_by() counts records per month without downloading them all:

Code 
frogs_month <- galah::galah_call() %>%
  galah::galah_identify("Litoria moorei") %>%
  galah::galah_filter(year >= 2000,
                      cl22 == "Western Australia",
                      dataResourceName == "FrogID") %>%
  galah::galah_group_by(month) %>%
  galah::atlas_counts() %>%
  dplyr::mutate(month = lubridate::month(as.numeric(month), label = TRUE)) # 1 -> Jan

ggplot2::ggplot(frogs_month, ggplot2::aes(x = month, y = count)) +
  ggplot2::geom_col(fill = "#e12744") +
  ggplot2::labs(x = NULL, y = "Number of records") +
  ggplot2::theme_bw()
ImportantCitizen science records are not standardised surveys

ALA records come from citizen scientists and researchers. Recording effort is not standardised: it depends on when and where people go out, which is especially true for rare species. A month with few records may mean fewer frogs calling, or fewer people listening. This kind of plot only shows real seasonal activity if survey effort is the same across the year. Remember from Research Design: “not recorded” is not the same as “absent”.

Types of spatial data

Spatial data come in two main forms:

  • Vector data are made of points (e.g. survey sites, occurrence records), lines (e.g. rivers, roads) and polygons (e.g. reserves, lakes, state boundaries). This tutorial used points and polygons.
  • Raster data are grids of cells, each with a value, used for continuous variables such as rainfall, temperature, elevation or vegetation cover.

Analysing spatial data

Spatial analysis is beyond this unit, but here are some possibilities:

  • Spatially explicit regression: sites close together tend to be similar (spatial autocorrelation), which breaks the independence assumption. Spatial models account for this. See Coding Club’s spatial modelling tutorial.
  • Species distribution models relate occurrence records to environmental predictors (climate, soil, habitat) to predict where a species could occur. They are used in conservation planning and to predict the effects of climate change and the spread of invasive species.
  • Movement ecology: see the optional Week 10.
