Week 10: Cleaning and plotting animal tracking data

This is an optional tutorial for anyone working with animal tracking (telemetry) data.

Note

This tutorial is optional and not assessed, and it will not be in the exam. Work through it in your own time if tracking data are relevant to your project.

Tracking data combine location and time, so this tutorial builds on the optional time series and spatial data tutorials.

Tracking technologies

How do we track animals in the wild? There are many methods, and how you process, analyse and interpret movement data depends heavily on the method used.

  • Marking
  • Radio telemetry
  • Satellite telemetry
  • Acoustic telemetry
  • Onboard loggers

The simplest and cheapest method uses capture–mark–recapture or direct observation of marked animals. It is time-consuming, and following or recapturing animals can disturb their behaviour. It is still widely used, for example to monitor bird movements through citizen science reports of leg bands. Example study: (Counilh and Arnould, 2023).

VHF radio telemetry: a small transmitter (usually < 5% of the animal’s body mass) emits a very high frequency (VHF) radio signal that the researcher tracks with a receiver and antenna. Tags are cheap, light and have long battery lives, which suits terrestrial and semi-aquatic animals (e.g. freshwater turtles). However, tracking is labour intensive and gives only a few locations per day. Automated networks such as MOTUS use fixed receivers to detect tags continuously. Example study: (Yu et al., 2022).

Radio-frequency identification (RFID): tiny, battery-free passive integrated transponder (PIT) tags are detected when an animal passes close to an antenna, for example at cave entrances to record when bats move between caves. Example study: (Harten et al., 2022).

GPS telemetry: tags (collars, backpacks, harnesses) record locations from satellites, often many per hour. GPS tags are among the most expensive options. GSM (cellular) tags upload data over the mobile network, so you do not need to recover the tag, but they need phone coverage. Example study: (Peel et al., 2024).

Argos satellite telemetry: tags (platform transmitter terminals, PTTs) send signals to satellites, which estimate the location from the Doppler shift. Argos locations are less accurate than GPS (up to kilometres), but tags can last months to years, which suits large, wide-ranging species such as sharks, turtles and seals. Example study: (Hoenner et al., 2012).

Radio signals do not travel through salt water, so most underwater tracking uses acoustic tags, which send coded sound pulses to fixed or mobile receivers. Tags can last for years, but you only detect animals near a receiver, so the design of the receiver array is crucial. It works best in confined habitats such as rivers, estuaries and reefs. Example study: (Baker et al., 2023).

Accelerometers measure acceleration in three axes (the same technology as in smartwatches). They can show activity levels, classify behaviours (foraging, resting, hunting) and estimate energy expenditure. Behaviours must first be calibrated against known behaviours, and accelerometers do not record location, so they are often combined with GPS or VHF tags. Example study: (Wild et al., 2025).

Biologgers record other variables such as light, temperature, depth, heart rate or internal body temperature. Example study: (Royer et al., 2023).

Process GPS data

Basic tracking data contain the ID of each animal, its location (longitude and latitude) and the date and time of each location (a fix). Here we use GPS data from three red-footed boobies (Sula sula) nesting on Diego Garcia in the Indian Ocean. We loosely follow the ExMove workflow for cleaning and processing tracking data (Langley et al., 2024).

Download the three GPS files and the metadata file, and save them in a folder called gps_study inside your data folder.

Now tidy the columns. The bird ID is the first 7 characters of the file name (e.g. “GV37501” from “GV37501_201606_DG_RFB.csv”), which stringr::str_sub() extracts. This only works because every ID has the same length and position.

Code 
gps_data <- gps_raw %>%
  dplyr::mutate(
    file_name = basename(file_name),                          # drop the folder from the name
    ID        = stringr::str_sub(file_name, start = 1, end = 7),
    Date      = lubridate::parse_date_time(Date, orders = c("dmy", "ymd")), # files use different formats
    date_time = lubridate::ymd_hms(paste(as.Date(Date), Time), tz = "GMT"),  # GPS time is in GMT
    lon       = Longitude,
    lat       = Latitude) %>%
  dplyr::select(ID, date_time, lon, lat) %>%                  # keep only the columns we need
  dplyr::arrange(ID, date_time)                               # order by bird, then time

Movement metrics

To find impossible fixes, calculate for each fix (within each bird):

  • the distance from the previous fix,
  • the time since the previous fix,
  • the speed (distance / time),
  • the net displacement: the distance from the first fix (the nest).

geosphere::distHaversine() calculates the distance in metres between two sets of longitude/latitude points, allowing for the curvature of the Earth. dplyr::lag() gives the previous value, and dplyr::first() the first value.

Code 
gps_metrics <- gps_merged %>%
  dplyr::group_by(ID) %>%                                       # calculate within each bird
  dplyr::mutate(
    dist_m     = geosphere::distHaversine(cbind(lon, lat), cbind(dplyr::lag(lon), dplyr::lag(lat))),
    time_s     = as.numeric(difftime(date_time, dplyr::lag(date_time), units = "secs")),
    speed_ms   = dist_m / time_s,                               # metres per second
    netdisp_km = geosphere::distHaversine(cbind(lon, lat), cbind(dplyr::first(lon), dplyr::first(lat))) / 1000) %>%
  dplyr::ungroup()

Filter out errors

Choose thresholds from the biology of your species (and the literature), then filter:

  • Deployment period: remove the first 30 minutes after the tag was attached, when the bird may behave unnaturally after handling.
  • Speed: red-footed boobies rarely fly faster than about 20 m/s, so faster “movements” are GPS errors.
  • Net displacement: these birds were rearing chicks and returning to the nest, so fixes more than 300 km away are errors.

If your GPS data have a dilution of precision (DOP) column, you can also remove fixes with poor precision (e.g. DOP > 8).

Code 
gps_clean <- gps_metrics %>%
  dplyr::filter(date_time > deploy_time + lubridate::minutes(30), # after the first 30 min
                is.na(speed_ms) | speed_ms < 20,                 # keep the first fix (no speed) and realistic speeds
                netdisp_km <= 300)                               # within 300 km of the start

# How many fixes were removed for each bird?
dplyr::left_join(dplyr::count(gps_metrics, ID, name = "before"),

Longitude and latitude are in degrees (CRS code EPSG:4326). geosphere handles these directly. If you combine tracks with other maps or rasters (e.g. habitat or sea surface temperature), make sure every layer uses the same coordinate reference system, and use a projected CRS in metres for area calculations such as home ranges. Other tracking data

Other technologies need different cleaning steps:

  • Argos tags: each location has a location class (accuracy category) instead of a DOP. Error estimates differ among classes, and tracks are often processed with state-space models.
  • Acoustic telemetry: sound signals are easily corrupted, so false detections occur. Detections of tag IDs that are not in your study are easy to remove, but false detections of real tag IDs are harder to spot. Most studies use speed filters or summarise detections over longer time periods.

Analysing movement data

Movement analysis is beyond this unit, because it needs models that handle autocorrelated, multidimensional (x, y, time) and irregularly sampled data. Some possibilities:

  • Home range / space use: minimum convex polygons (MCP), kernel density estimates (KDE) and autocorrelated KDE (AKDE).
Method Complexity Data needed Gives intensity of use? Best for
MCP Very simple Low (≥ 30 points) No Coarse, presence-only questions
KDE Moderate Moderate (≥ 50 points) Yes Core areas
AKDE High High (≥ 100 points) Yes Rigorous inference from intensive GPS data
ImportantHome range or space use?

A home range is “that area traversed by an individual in its normal activities of food gathering, mating and caring for young” (Burt, 1943). Tracking data alone cannot show whether an area is used for all these activities, and an animal tracked for one season may use a completely different area in another. The safest term is space use, interpreted in the context of the study design (e.g. one week vs several months of tracking).

  • Behavioural states: high-resolution movement and accelerometer data can separate resting, foraging and travelling using methods such as hidden Markov models.
  • Social networks: when and where tracked animals meet can be used to build social networks.
  • Disease spread: movement data help predict how diseases spread through populations, as seen for COVID-19.
