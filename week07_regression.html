Week 7: Relationships between a response and one or more numeric predictors

In Week 5 you compared groups. This week the predictor is a number (latitude, temperature, chlorophyll) and we ask how the response changes as that number changes. You will fit a simple linear regression (one predictor) and then a multiple regression (several predictors). Workshop materials are available in the GitHub repository ECS200.

TipLearning outcomes

By the end of this workshop you should be able to:

  1. Explain what the intercept, slope and R2 of a regression mean.
  2. Use diagnostic plots to check linearity, equal variance, normality and influential points.
  3. Recognise collinearity between predictors and decide what to do about it.
  4. Fit, visualise and write up simple and multiple regression models in R.

Part A: Simple linear regression

Question: Are fiddler crabs bigger at higher latitudes (Bergmann’s rule)?

Bergmann’s rule predicts that individuals of a species are larger in colder places, which usually means at higher latitudes. In summer 2016, researchers measured the carapace width of adult male Atlantic marsh fiddler crabs (Minuca pugnax) at 13 salt marshes spanning more than 12 degrees of latitude, from Florida to Massachusetts (Johnson, 2019). 1. Background

A simple linear regression fits the straight line that best describes how a numeric response (y) changes with a numeric predictor (x):

\[ y_i = \beta_0 + \beta_1 x_i + \varepsilon_i \]

  • \(\beta_0\) is the intercept: the predicted y when x = 0.
  • \(\beta_1\) is the slope: how much y changes, on average, for every one-unit increase in x. This is usually the number your research question is about.
  • \(\varepsilon_i\) is the residual: the vertical distance between each point and the line. Residuals are assumed to be normally distributed with constant spread.

R finds the line that makes the sum of the squared residuals as small as possible (least squares). The null hypothesis is that the slope is zero (no relationship).

A straight line is only a good summary if the relationship really is straight. In the app below, choose a pattern and compare the diagnostic plots with the ideal: a flat, patternless cloud in the residuals plot and points along the line in the Q-Q plot.

lin_data = {
  const r = rng(707 + lin_seed);
  const n = 80;
  const x = runif(r, n, 0, 4);
  const e = rnorm(r, n, 0, 1);
  let y;
  if (lin_type === "up") y = x.map((v, i) => 1 + 1.5 * v + e[i]);
  if (lin_type === "down") y = x.map((v, i) => 8 - 1.5 * v + e[i]);
  if (lin_type === "curve") y = x.map((v, i) => 1 + 0.6 * v ** 3 + 2 * e[i]);
  if (lin_type === "fan") y = x.map((v, i) => 2 + 1.2 * v + e[i] * (0.2 + 1.1 * v));

  return {pts, fit};
}

Leverage measures how unusual a point’s x value is. Cook’s distance combines leverage with the size of the residual. A point is only a problem when it is both unusual in x and far from the line. Never delete a point just because it is influential. Check whether it is a data entry error (Week 1) and, if it is real, report the results with and without it.

The output gives everything you need:

  • Residuals: a summary of the residuals. The median should be close to 0, and the minimum and maximum (and 1Q and 3Q) roughly the same distance from it.
  • Coefficients: one row for the intercept and one for the slope.
    • Estimate: (Intercept) is the predicted width at latitude 0; latitude is the slope, the change in width (mm) per degree of latitude. A positive slope means width increases with latitude.
    • Std. Error: the uncertainty in each estimate.
    • t value: the estimate divided by its standard error.
    • Pr(>|t|): the p-value for the null hypothesis that the coefficient is 0 (for the slope: no relationship).
  • Residual standard error: the typical distance of a crab from the fitted line (mm), with its degrees of freedom (number of crabs − 2).
  • Multiple R-squared: the proportion of variation in width explained by latitude. Adjusted R-squared is slightly lower because it penalises extra predictors; it matters more in multiple regression.
  • F-statistic ... on 1 and ... DF, p-value: compares this model with a model that has no predictor. With one predictor its p-value equals the slope’s p-value.
  • confint(): the 95% confidence intervals (2.5 % to 97.5 %) for the intercept and slope. If the slope’s CI does not include 0, the relationship is significant at α = 0.05.

5. Interpret

The fitted model is:

\[ \widehat{\text{width}} = -3.62 + 0.485 \times \text{latitude} \]

  • Slope (0.485): carapace width increases by about 0.49 mm for every degree further north (95% CI 0.42–0.55 mm). Across the 12 degrees sampled, that is about 5.8 mm.
  • Intercept (-3.62): the predicted width at latitude 0 (the equator). This is outside the range of the data and a negative width is impossible, so the intercept has no biological meaning here. That is common, and fine.
  • R2 (0.35): latitude explains 35% of the variation in carapace width. The rest is variation among individual crabs.
  • F-test at the bottom: compares this model with a model that has no predictor. With one predictor its p-value equals the slope’s p-value.

Methods sentence: The relationship between carapace width and latitude was analysed with a simple linear regression using the lm() function in R. Model assumptions were checked with diagnostic plots using the performance package. Significance was set at α = 0.05.

Results sentence:

Consistent with Bergmann’s rule, fiddler crabs were larger at higher latitudes. Carapace width increased by 0.49 mm per degree of latitude (95% CI 0.42–0.55; F1,390 = 208.5, p < 0.001, R2 = 0.35; Fig. 1). Because crabs were sampled from only 13 marshes, this p-value is likely too small (see Week 12).

1. Background

Multiple regression adds more predictors to the same equation:

\[ y_i = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \dots + \varepsilon_i \]

Each slope is now a partial effect: the change in y for a one-unit change in that predictor while all other predictors are held constant. This lets you separate the effects of predictors that would otherwise be tangled together, for example temperature and fishing.

Predictors can be numbers or categories. For a categorical predictor such as fishing_allowed, the coefficient is the difference in mean y between that category and the reference category (here “No”).

Collinearity is the big trap. When two predictors are strongly correlated with each other (e.g. chlorophyll is high close to land and low far from land), the model cannot tell which one is responsible. The estimates become unstable: standard errors grow, slopes can flip sign, and neither predictor may look significant even though together they explain a lot (Dormann et al., 2013). The variance inflation factor (VIF) measures this. VIF < 5 is fine, 5–10 is worrying and > 10 is serious.

App: what collinearity does to your estimates

col_sims = {
  const r = rng(909 + col_seed);
  const out = [];
  for (let s = 0; s < 300; s++) {
    const x1 = rnorm(r, col_n), e = rnorm(r, col_n), noise = rnorm(r, col_n);
    const x2 = x1.map((v, i) => col_r * v + Math.sqrt(1 - col_r ** 2) * e[i]);
    const y = x1.map((v, i) => 1 + 0.5 * v + 0.5 * x2[i] + noise[i]);
    out.push(lm2(x1, x2, y).b1);

  return out;
}

WarningCommon mistakes with multiple regression (click to expand)
  • Too many predictors for the data. A rough rule is at least 10–20 observations per predictor. With 72 sites, 4–5 predictors is the maximum.
  • Choosing predictors by trial and error (adding and removing them until something is significant, or automated “stepwise” selection). This produces over-confident p-values. Decide which predictors to include before you analyse, based on your hypotheses, and keep non-significant predictors in the model (Harrison et al., 2018; Popovic et al., 2024).
  • Comparing the size of slopes measured in different units. A slope of −3.7 for chlorophyll and −0.26 for SST cannot be compared directly, because a 1-unit change means very different things for each.
  • Interpreting a slope outside the range of the data (extrapolation).

The output has the same parts as for the simple regression, with a few differences:

  • Coefficients: one row per predictor. Each Estimate is a partial effect: the change in diversity for a one-unit increase in that predictor, holding the others constant.
    • (Intercept): predicted diversity when every numeric predictor is 0 and fishing is “No” (the reference level). Not meaningful here (no reef has a pH of 0).
    • sst, pH, chlorophyll: the change in diversity per °C, per pH unit and per mg/m3.
    • fishing_allowedYes: the difference in mean diversity between fished (“Yes”) and unfished (“No”) reefs, at the same SST, pH and chlorophyll.
    • Std. Error, t value and Pr(>|t|): as before, one test for each predictor.
  • Residual standard error ... on ... degrees of freedom: the df is now the number of sites minus the number of coefficients (72 − 5 = 67).
  • Multiple R-squared and Adjusted R-squared: the proportion of variation explained by all predictors together. Report the adjusted R2 when comparing models with different numbers of predictors, because R2 always increases when you add one.
  • F-statistic: tests whether the predictors together explain more than a model with no predictors. It can be significant even when no single predictor is.
  • confint(): the 95% CIs for each coefficient. A CI that includes 0 means no clear effect of that predictor.

The best way to understand a multiple regression is to plot its predictions. ggeffects::predict_response() predicts diversity across the range of one predictor while holding the other predictors at their average (or reference level).

5. Interpret

Each slope is the change in Shannon diversity for a one-unit increase in that predictor, holding all the other predictors constant:

Predictor Estimate 95% CI p Meaning
Chlorophyll -3.7 -4.24 to -3.16 < 0.001 Diversity drops by 0.37 for every 0.1 mg/m3 increase in chlorophyll
SST -0.26 -0.37 to -0.14 < 0.001 Diversity drops by 0.26 per 1 °C warmer
Fishing allowed (Yes vs No) -0.26 -0.4 to -0.13 < 0.001 Fished reefs are 0.26 lower in diversity
pH 5.93 -6.27 to 18.12 0.335 No clear effect: the CI is very wide and includes 0

A non-significant result for pH does not prove pH has no effect. pH varied very little among these sites (8.08–8.11), so the data contain little information about it.

Results sentence:

Coral diversity was lower at reefs with higher chlorophyll-a concentrations (β = -3.7, 95% CI -4.24 to -3.16, p < 0.001), higher sea surface temperatures (β = -0.26 per °C, 95% CI -0.37 to -0.14, p < 0.001) and where commercial fishing was allowed (0.26 lower, 95% CI 0.13–0.4, p < 0.001), but showed no clear relationship with pH (p = 0.34). Together these predictors explained 77% of the variation in diversity (F4,67 = 56.1, p < 0.001; Fig. 2). Distance from land was excluded because it was strongly correlated with chlorophyll (r = −0.97).
